# 坦克大战 · Tank Battle

一个用纯 HTML5 + Canvas + JavaScript 编写的经典坦克大战（Battle City 风格）网页小游戏，单文件即可运行，无需任何依赖。

## 玩法

- 操控我方坦克，**保卫右下角的基地（金鹰）**，并消灭关卡内的所有敌方坦克。
- 敌人会不断从上方刷新并向下进攻，向你的基地推进。
- 基地一旦被炮弹击中，游戏即告结束。

## 操作

| 操作 | 键盘 | 说明 |
| ---- | ---- | ---- |
| 移动 | `WASD` / 方向键 | 四个方向 |
| 射击 | `空格` / `J` | 按住连发 |
| 暂停 | `P` / `Esc` | 暂停 / 继续 |
| 静音 | `M` | 开关音效 |
| 开始 / 重开 | `Enter` | 菜单 / 结算界面 |

> 移动端（触屏设备）会自动显示虚拟方向键和开火按钮。

## 游戏元素

- 🧱 **砖墙**：可被炮弹摧毁，提供临时掩体。
- 🛡️ **钢墙**：普通炮弹无法摧毁，需「强化炮弹」。
- 🌊 **河流**：坦克无法通过，炮弹可穿过。
- 🌲 **树林**：坦克可穿过，并隐藏其中（覆盖在坦克之上）。
- ⭐ **强化炮弹**：击碎钢墙、射速更快、可同时两发。
- ❤️ / 🛡️ / ★ / 💣 **道具**：额外生命、护盾、强化炮弹、全屏炸弹。

## 运行

直接双击打开 `index.html`，或在任意静态服务器中托管即可（如 `python -m http.server`）。

## 说明

- 分数记录会保存在浏览器 `localStorage` 中（最高分）。
- 关卡会随着进度不断增加敌人数量和强度。
